# Portfolio Admin

This is the standalone admin frontend for the portfolio.

## Local development

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Open:

```
http://localhost:5174
```

## Backend API

The admin app expects the backend API to be available at `http://localhost:5000/api` by default.

You can change the URL by setting `VITE_API_URL`.
