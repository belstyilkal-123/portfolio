# Portfolio Monorepo

This repository contains a professional portfolio website with separated frontend, backend, and admin portal code.

## Repository structure

- `frontend/`
  - React + Vite portfolio application
  - Public portfolio pages in `frontend/src/pages/`
  - Admin portal pages in `frontend/src/admin/`
- `backend/`
  - Express API with authentication, project management, and message handling
- `dist/`
  - Built artifacts generated by the build process

## Frontend structure

- `frontend/src/pages/`
  - Public portfolio pages: `Dashboard`, `About`, `Projects`, `Skills`, `Contact`, and more.
- `frontend/src/admin/`
  - Admin portal pages: `Login`, `Register`, `AdminDashboard`, `ManageProjects`, `ManageMessages`.
- `frontend/src/layouts/`
  - Shared layout components for public pages and admin UI.

## Admin portal

- `/admin/login`
- `/admin/register`

### Auth endpoints

- `POST /api/auth/login`
- `POST /api/auth/register`

The first user created through `/api/auth/register` is assigned `isAdmin: true`.

## Run locally

Install dependencies from the repo root:

```bash
npm install
```

Start frontend and backend together:

```bash
npm run dev
```

Seed the backend sample data and create the default admin user:

```bash
npm run seed
```

Or run individually:

```bash
npm run dev:frontend
npm run dev:backend
```

## Build

```bash
npm run build
```

This command builds both frontend and backend.
